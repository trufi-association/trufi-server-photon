# Photon Server

Geocoding server using [Photon](https://photon.komoot.io) by [Komoot](https://komoot.de) for the [Trufi Association](https://trufi-association.org) stack.

Provides address search and reverse geocoding (coordinates → place name) for transit applications.

## Requirements

- Docker and Docker Compose
- Internet connection (to download data)
- `wget`, `tar`, `bzip2` (for the init script)

## Quick Start

### 1. Download country data

Run the interactive script that shows all available countries:

```bash
./init.sh
```

The script will:
- Check that you have the required dependencies
- Show the list of available countries from GraphHopper
- Let you select a country by ISO code (e.g., `rw`, `bo`, `us`)
- Download and extract the data automatically

### 2. Start the server

```bash
docker-compose up -d --build
```

### 3. Verify it's working

```bash
# Direct access (if ports are enabled)
curl 'http://localhost:2322/api?q=kigali'

# Through nginx (default configuration)
curl 'http://localhost/photon/api?q=kigali'
```

## Configuration

### Ports

By default, port 2322 is commented out in `docker-compose.yml` because the service is accessed through nginx. For direct access, uncomment:

```yaml
ports:
  - 2322:2322
```

### Memory

The memory limit is set to 2GB (`mem_limit: 2g`). Adjust according to the country data size:

- Small countries: 1-2 GB
- Medium countries: 2-4 GB
- Large countries (US, BR, etc.): 4-8 GB

### Nginx

Include the `nginx.conf` file in your nginx configuration:

```nginx
location /photon/ {
    proxy_pass http://photon:2322/;
}
```

## API

Photon API usage examples:

```bash
# Simple search
curl 'http://localhost:2322/api?q=airport'

# Search with result limit
curl 'http://localhost:2322/api?q=hotel&limit=5'

# Search with location filter (lat, lon)
curl 'http://localhost:2322/api?q=restaurant&lat=-1.9403&lon=29.8739'

# Reverse geocoding
curl 'http://localhost:2322/reverse?lat=-1.9403&lon=29.8739'
```

## Troubleshooting

### Container won't start

1. Verify that `photon_data/` exists and has data:
   ```bash
   ls -la photon_data/
   ```

2. Check the logs:
   ```bash
   docker-compose logs photon
   ```

### Memory errors

If you see Java heap space errors, increase `mem_limit` in `docker-compose.yml`.

### Corrupted data

Delete and re-download:
```bash
rm -rf photon_data/
./init.sh
```

## Data Source

Data comes from [GraphHopper](https://download1.graphhopper.com/public/extracts/by-country-code/), periodically updated with OpenStreetMap data.

## Docker Network

This service connects to the `trufi-server` network shared with other Trufi services.
